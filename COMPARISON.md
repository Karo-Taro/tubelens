# TubeLens vs vidIQ — сравнение функций

Источники по vidIQ: публичная страница расширения «vidIQ Vision for YouTube» в Chrome Web Store и vidiq.com/features (на октябрь 2026). Платный кабинет vidIQ не изучался — сравниваем с тем, что vidIQ публично заявляет.

✅ есть · 🟡 частично или иначе · ❌ нет

## Расширение vidIQ (на youtube.com и в Studio)

| Функция vidIQ | TubeLens | Как устроено у нас |
|---|---|---|
| vidIQ Score / Scorecard видео | ✅ | SEO-оценка 0–100 по открытому чеклисту из 14 пунктов (`lib/scoring.js`) + VPH, вовлечённость, ×к медиане канала. Показывается в панели на странице видео и в разделе «Анализ видео». У vidIQ формула закрытая |
| Video Velocity (просмотры в час) | 🟡 | Средний VPH за всю жизнь видео — на странице видео и бейджами на всех карточках. «Живого» VPH за последний час нет: для него нужны периодические замеры |
| Средняя длительность просмотра | ❌ | Доступна только владельцу канала через YouTube Analytics API (OAuth) |
| Отслеживание конкурентов | ✅ | Раздел «Конкуренты»: таблица сравнения и общая лента их новых видео с отметкой аутлаеров |
| SEO-теги любого видео | ✅ | Теги в панели на странице видео и в «Анализе видео», копирование по одному и всех сразу; теги канала в боковой панели канала |
| Экспорт в CSV | 🟡 | Есть в оверлее «Фильтры» на YouTube (выдача поиска, видео канала). В таблицах самого приложения CSV пока нет |
| Превью обложки/заголовка в Studio | ❌ | См. «Что ещё можно добавить» |
| Соцметрики (Facebook, X, Reddit) | ❌ | Публичные API этих сетей фактически закрыты |
| Советы по описанию | ✅ | Пункты чеклиста про описание (длина, ключ в начале, таймкоды, хэштеги) + AI-переписывание |
| Инструменты в редакторе YouTube Studio | ❌ | AI-инструменты есть в панели TubeLens, но в Studio не встроены |
| Boost (подбор ключей для старых видео) | 🟡 | «Оптимизация видео» в AI-студии и AI-оптимизация в «Анализе видео» — по одному видео |
| Оценка запроса на странице поиска | ✅ | Панель с оценкой ключевого слова прямо в выдаче YouTube |
| Статистика канала на странице канала | ✅ | Боковая панель: подписчики, общие просмотры, график накопленных просмотров, история подписчиков из ваших замеров, теги канала, аутлаеры, AI-разбор |
| Фильтры и сортировка выдачи | ✅ | Оверлей «Фильтры»: пресеты («Скрытые жемчужины», «Взлетают», «Вечнозелёные», «Топ за сутки» и др.), свои фильтры по просмотрам, подписчикам, множителю ×, VPH, длительности, дате; сортировка; CSV |

## Чего нет у vidIQ, но есть в TubeLens

- **Работа без ключа и без аккаунта**: данные с публичного сайта YouTube (InnerTube), анонимно.
- **Любой AI**: 18 пресетов (OpenAI, Anthropic, Gemini, OpenRouter, Groq, DeepSeek, Mistral, Together, Fireworks, xAI, Perplexity, Cerebras, Ollama, LM Studio, LiteLLM, CLIProxyAPI и др.) или свой OpenAI/Anthropic-совместимый эндпоинт.
- **AI без API-ключа** — через установленный CLI (Claude Code, Codex CLI, Gemini CLI, Ollama) и локальный помощник TubeLens.
- **Скачивание видео и аудио** через yt-dlp (лучшее, 1080p, 720p, 480p, m4a, MP3) и скачивание обложек.
- **Проверка позиции** видео в поиске по запросу (топ-50).
- **AI-анализ комментариев**: настроение, вопросы аудитории, идеи для видео.
- **Открытые формулы**: все оценки в `lib/scoring.js`, их можно менять.
- **Темы оформления**, которые распространяются и на панели на youtube.com.
- **Приватность**: нет своего сервера; ключи, настройки и замеры хранятся только в браузере.

## Что ещё можно добавить

Только то, что реально сделать без платных API и без своего сервера. Оценка трудозатрат: **S** — до дня, **M** — несколько дней, **L** — неделя и больше.

| # | Идея | Трудоёмкость | Как |
|---|---|---|---|
| 1 | CSV-экспорт во всех таблицах приложения (ключи, аудит, конкуренты, аутлаеры) | S | Переиспользовать генератор CSV из `content/filters.js` в `app/ui.js` (`videoTable`) |
| 2 | Trend Alerts: новые аутлаеры в нише и новые видео конкурентов | M | `chrome.alarms` + `chrome.notifications` (два новых разрешения), сравнение с прошлой проверкой в storage |
| 3 | Фоновые замеры своего канала (настоящий Real-Time Stats и график подписчиков) | S–M | Тот же `chrome.alarms`: снимок раз в 1–6 часов вместо замеров только при заходе на YouTube |
| 4 | Массовая SEO-проверка своего канала | M | Прогнать `videoSeo` по всем видео канала, таблица «что исправить» с сортировкой по просмотрам |
| 5 | Превью обложки и A/B-макет на «фальшивой» сетке YouTube | M | Загрузка своей картинки + заголовка, отрисовка среди реальных карточек выдачи по запросу (светлая/тёмная тема, мобильный вид) |
| 6 | A/B-тестер заголовков | S | AI генерирует варианты, сравнение по чеклисту (длина, ключ, эмоция), предпросмотр обрезки на десктопе и мобильном |
| 7 | Интеграция в редактор YouTube Studio | L | Контент-скрипт на studio.youtube.com: оценка заголовка/описания/тегов на лету и кнопки AI. Вёрстка Studio часто меняется |
| 8 | Перевод заголовка и описания через AI | S | Новый инструмент в `lib/prompts.js` (несколько языков разом, с сохранением ключей) |
| 9 | Нарезка Shorts через помощник | L | Новая команда помощника: yt-dlp скачивает отрезок, ffmpeg режет и кадрирует 9:16; выбор моментов — по таймкодам или AI по субтитрам |
| 10 | Вехи и достижения | S | По локальной истории замеров: «10K подписчиков», «рекорд просмотров за сутки», прогноз до следующей вехи |
| 11 | Генерация обложек | M | Через API изображений с ключом пользователя (OpenAI Images и т. п.) — по аналогии с AI-пресетами |
| 12 | Удержание и CTR своего канала | L | OAuth + YouTube Analytics API; требует своего OAuth-клиента Google и проверки приложения |

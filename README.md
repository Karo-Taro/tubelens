# TubeLens — открытый инструмент для роста на YouTube

**by [YT Cartel](https://t.me/YT_cartell)** · [Telegram-канал](https://t.me/YT_cartell) · [Исходный код](https://github.com/Karo-Taro/tubelens) · [Сообщить об ошибке](https://github.com/Karo-Taro/tubelens/issues)

Бесплатное расширение для Chrome (и других браузеров на Chromium) с открытым кодом под лицензией MIT. Внутри исследование ключевых слов, SEO-оценка видео, аудит каналов, конкуренты, аутлаеры, AI-студия и AI-коуч, загрузка видео, а также панели прямо на youtube.com.

**Без подписок, без аккаунтов, без своего сервера.** Ключ YouTube API не обязателен. AI можно подключить без API-ключа через CLI-агента на вашем компьютере. Все настройки, ключи и замеры хранятся только в вашем браузере.

### На youtube.com

- **Страница видео** — панель с SEO-оценкой, тегами, VPH, вовлечённостью, кнопками загрузки видео и обложки и переходом в полный анализ.
- **Страница поиска** — оценка ключевого слова и подсказки прямо в выдаче.
- **Карточки видео** (главная, поиск, каналы, похожие) — бейджи VPH и множитель ×N к медиане канала.
- **Страница канала** — боковая панель: подписчики, общие просмотры, график накопленных просмотров, история подписчиков по вашим замерам, теги канала, аутлаеры, AI-разбор.
- **Панель на странице видео** с вкладками «Обзор / SEO / Канал / AI»: SEO-оценка, VPH, вовлечённость, ×N к медиане канала, чеклист, теги с копированием, оценка ключа, сравнение с каналом, AI-улучшения и перевод на 10 языков. Закрепляется над виджетами других расширений.
- **«Фильтры»** — оверлей поверх выдачи и видео канала: пресеты («Скрытые жемчужины», «Взлетают», «Вечнозелёные», «Топ за сутки», «Аутсайдеры» и др.), свои фильтры по просмотрам, подписчикам, множителю ×, отношению просмотров к подписчикам, длительности и дате, сортировка, выгрузка в CSV.
- **Шапка YouTube** — компактная плашка со статистикой вашего канала (подписчики, просмотры, видео) и приростом к замеру примерно суточной давности.

Все панели на YouTube окрашиваются в тему, выбранную в настройках TubeLens.

Сравнение с vidIQ и список идей для доработки — в [COMPARISON.md](COMPARISON.md).

## Установка (режим разработчика)

1. Скачайте или клонируйте репозиторий.
2. Откройте `chrome://extensions` и включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное** и выберите папку `tubelens` (ту, где лежит `manifest.json`).
4. Нажмите на иконку расширения — откроется боковая панель. Через ПКМ по иконке → «Открыть TubeLens во вкладке» или кнопку в шапке панели — полноэкранный режим.

ID расширения закреплён ключом в `manifest.json`: `mnaoadllhdlnmdccgppbbicpplfihceh`. Он нужен помощнику загрузки.

## Данные YouTube: ключ не обязателен

Без ключа TubeLens берёт данные с публичного сайта YouTube через внутренний API InnerTube — анонимно, как гость в режиме инкогнито. Так работают поиск, каналы, видео, теги, лайки и комментарии. Реализация в `lib/innertube.js`: если YouTube поменяет формат ответов, править нужно только этот файл.

Что даёт ключ: точное число подписчиков (без ключа YouTube округляет, например «21.4M»), общее число просмотров канала, вовлечённость в списках видео, раздел «В тренде».

**Как получить ключ YouTube Data API:**
1. [Google Cloud Console](https://console.cloud.google.com/apis/library/youtube.googleapis.com) → создайте проект → включите **YouTube Data API v3**.
2. *Credentials → Create credentials → API key*. Вставьте ключ в **Настройки**.
3. Лимит — 10 000 единиц в сутки: поиск стоит 100 ед., остальные запросы — 1 ед. Счётчик виден в шапке, ответы кэшируются.

## AI

В **Настройках** выберите пресет или впишите свой эндпоинт. Поддерживаются два формата: OpenAI `/chat/completions` и Anthropic `/messages`.

- **Облачные провайдеры со своим ключом:** OpenAI, Anthropic, Google Gemini, OpenRouter, Groq, DeepSeek, Mistral, Together, Fireworks, xAI, Perplexity, Cerebras и любой OpenAI-совместимый URL.
- **Без API-ключа, через CLI-агента на вашем компьютере.** Пресет «CLI-агент на этом компьютере»: помощник TubeLens (см. ниже) принимает OpenAI-совместимые запросы на `http://127.0.0.1:47321/v1` и передаёт текст установленному CLI, в котором вы уже вошли в аккаунт: `claude` (Claude Code), `codex` (Codex CLI), `gemini` (Gemini CLI) или `ollama/<модель>`. CLI запускается в пустой временной папке без доступа к инструментам: Claude Code — с `--tools ""`, Codex — в песочнице `read-only`. Так текст чужих видео не сможет заставить агента выполнить команду. Одновременно работают не больше двух запросов, таймаут 5 минут.
  Свои команды добавляются в `%LOCALAPPDATA%\TubeLens\config.json` (на macOS/Linux — `~/.local/share/TubeLens/config.json`): `{"cli": {"my-llm": {"cmd": ["llm", "-m", "gpt-4o"]}}}`. Текст запроса передаётся в stdin. Из расширения приходит только имя команды, поэтому запустить через помощника произвольную программу нельзя.
- **Через локальный прокси:** пресеты LiteLLM Proxy (`localhost:4000`) и CLIProxyAPI (`localhost:8317`), а также Ollama (`localhost:11434`) и LM Studio (`localhost:1234`). Ollama запускайте с `OLLAMA_ORIGINS=chrome-extension://*`.
- Кнопка «Загрузить список» подтягивает модели через `GET /models`.
- При сохранении расширение запросит доступ к домену эндпоинта (`optional_host_permissions`). Для помощника TubeLens отдельное разрешение не нужно.

## Помощник TubeLens: загрузка видео и AI через CLI (необязательно)

Расширение не может само запускать программы, поэтому загрузку видео и вызов CLI выполняет небольшой локальный помощник на Python (`native-host/tubelens_dl.py`). Он работает в двух режимах:

- **Локальный HTTP-сервер** на `127.0.0.1:47321` — основной режим. Запускается вместе с системой и работает в любом браузере на Chromium, включая сборки без Native Messaging (например, Linken Sphere).
- **Native Messaging** — запасной вариант: браузер запускает помощника сам.

### Установка

1. Нужен Python 3. Для 1080p+ и MP3 нужен **ffmpeg**, для полной поддержки YouTube — **deno** (JS-движок для yt-dlp).
2. Запустите установщик из папки `native-host`:
   - **Windows:** дважды кликните `УСТАНОВИТЬ.bat`. Недостающие Python, ffmpeg и deno он поставит сам через winget, затем запустит `install_windows.ps1`.
   - **macOS / Linux:** `bash native-host/install.sh`.
3. Перезапустите браузер. Статус помощника виден в разделе «Загрузки», файлы сохраняются в `Загрузки/TubeLens`.

Что делает установщик:
- создаёт окружение Python вне папки расширения: `%LOCALAPPDATA%\TubeLens\venv` (macOS/Linux — `~/.local/share/tubelens/venv`) и ставит туда yt-dlp;
- регистрирует Native Messaging для Chrome, Edge, Brave и Chromium;
- записывает `config.json` с ID расширения, которому разрешён доступ (ваши свои CLI-команды при этом сохраняются);
- включает автозапуск HTTP-помощника: на Windows через ключ `HKCU\…\Run\TubeLensHelper`, на macOS через LaunchAgent `com.tubelens.helper`, на Linux через `systemd --user` (`tubelens-helper.service`). Чтобы не включать автозапуск на macOS/Linux, запустите установщик с `TUBELENS_NO_AUTOSTART=1`.

Если вы поменяли ключ в `manifest.json`, передайте новый ID: `install_windows.ps1 -ExtensionId <id>` или `bash install.sh <id>`. Установщик можно запускать повторно — он обновит yt-dlp и перезапустит помощника.

### Удаление

- **Windows:** `powershell -ExecutionPolicy Bypass -File native-host\install_windows.ps1 -Uninstall`. Помощник остановится, автозапуск и регистрация в браузерах будут удалены.
- **macOS / Linux:** `bash native-host/install.sh --uninstall`.
- Папка с окружением, настройками и логом (`%LOCALAPPDATA%\TubeLens` или `~/.local/share/tubelens` и `~/.local/share/TubeLens`) остаётся — удалите её вручную, если она не нужна.

### Безопасность помощника

- Слушает только `127.0.0.1`. Запросы принимаются только с заголовком `X-TubeLens: 1` и `Host` равным `127.0.0.1` или `localhost` — это защита от DNS-rebinding. Если запрос пришёл с `Origin`, это должно быть расширение из `allowed_origins`. Preflight-запросы от сайтов отклоняются, поэтому веб-страница не может обратиться к помощнику.
- Загрузка — только по http(s)-ссылкам и только в папку `Загрузки/TubeLens`. «Открыть папку» работает только внутри неё.
- Лог пишется в `helper.log` рядом с `config.json`. При размере больше 1 МБ он переименовывается в `helper.log.1`.
- Порт меняется переменной окружения `TUBELENS_PORT`. Учтите, что расширение обращается к порту 47321.

YouTube часто меняется: если загрузка перестала работать, нажмите «Обновить yt-dlp» в разделе «Загрузки».

## Оформление

7 тем — Графит, Полночь, Хвоя, Бордо, Высокий контраст, Бумага, Студия — и режим «Как в системе». Тема переключается кнопкой с палитрой в шапке или в **Настройки → Оформление** и применяется к приложению и ко всем панелям на youtube.com (`content/theme.js` берёт цвета из `app/themes.js`). Своя тема — это один объект в `app/themes.js`.

Шрифты встроены локально (`app/fonts`), сетевых запросов за ними нет: **Golos Text**, **Unbounded** и **JetBrains Mono** — все под лицензией SIL Open Font License 1.1 (`app/fonts/OFL.txt`, авторы перечислены в `app/fonts/FONTS.txt`).

## Приватность

- У TubeLens нет своего сервера, аналитики и телеметрии.
- Настройки, ключи API, сохранённые запросы, история замеров и кэш хранятся в `chrome.storage` вашего браузера. Экспорт настроек ключей не содержит.
- Запросы уходят только туда, куда нужно для работы: на youtube.com и googleapis.com (данные YouTube), suggestqueries (подсказки), выбранному вами AI-провайдеру и локальному помощнику на `127.0.0.1`.
- Текст, который вы отправляете в AI, обрабатывает выбранный вами провайдер по его правилам.

### Разрешения расширения

| Разрешение | Зачем |
|---|---|
| `storage`, `unlimitedStorage` | Настройки, кэш ответов и история замеров каналов (без ограничения в 10 МБ) |
| `sidePanel` | Боковая панель приложения |
| `contextMenus` | Пункт «Открыть TubeLens во вкладке» в меню иконки |
| `nativeMessaging` | Запасной способ связи с помощником загрузки |
| `downloads` | Сохранение обложек видео |
| `declarativeNetRequestWithHostAccess` | Сессионное правило подставляет `Origin`/`Referer` `https://www.youtube.com` только в собственные запросы TubeLens к `www.youtube.com/youtubei/`: с `Origin: chrome-extension://…` YouTube отвечает 403. Работает лишь на хостах из `host_permissions` и не показывает дополнительного предупреждения при установке |
| `host_permissions`: `www.youtube.com`, `www.googleapis.com`, `suggestqueries*` | Данные YouTube (без ключа и с ключом) и автоподсказки |
| `optional_host_permissions`: `http(s)://*/*` | Запрашивается по одному домену, только когда вы сохраняете свой AI-эндпоинт |

## Структура кода

```
manifest.json            MV3-манифест
background.js            service worker: боковая панель, контекстное меню, запросы контент-скриптов, замеры каналов
lib/
  storage.js             настройки, кэш с TTL, учёт квоты
  youtube.js             YouTube Data API и автоподсказки; без ключа переключается на innertube.js
  innertube.js           режим без ключа: поиск, каналы, видео через публичный API сайта
  scoring.js             все формулы: оценка ключей, SEO-чеклист, VPH, аутлаеры, аудит
  analysis.js            отчёты: ключ, видео, канал, аутлаеры, конкуренты, позиция в поиске
  ai.js                  универсальный AI-клиент (OpenAI / Anthropic)
  presets.js             пресеты AI-провайдеров        ← добавьте свой
  prompts.js             AI-инструменты и промпты      ← добавьте свой инструмент
  downloader.js          связь с помощником (HTTP или Native Messaging), очередь загрузок, обложки
app/                     интерфейс без сборки, чистый ES-модульный JS
  app.html, app.js       оболочка и роутер (боковая панель и вкладка — один код)
  ui.js, icons.js        общие компоненты и иконки
  themes.js              темы оформления
  app.css, styles/       стили: общие и по разделам (overview, analysis, studio)
  fonts/, fonts.css      локальные шрифты (SIL OFL)
  views/*.js             по файлу на раздел
content/                 всё, что встраивается в youtube.com
  theme.js               применяет выбранную тему к панелям на YouTube
  youtube.js/.css        панели видео, поиска и канала, бейджи на карточках
  filters.js/.css        оверлей «Фильтры» с пресетами и CSV
  masthead.js/.css       плашка статистики в шапке YouTube
native-host/
  tubelens_dl.py         помощник: HTTP-сервер / Native Messaging ↔ yt-dlp и CLI-агенты
  УСТАНОВИТЬ.bat         установка для Windows в один клик
  install_windows.ps1    установка и удаление для Windows
  install.sh             установка и удаление для macOS / Linux
```

Сборка не нужна: правьте файлы и нажмите «Обновить» на `chrome://extensions`. После правок в `content/` перезагрузите вкладку YouTube.

## Как помочь проекту

- **Новый AI-инструмент:** добавьте объект в `TOOLS` в `lib/prompts.js` — поля `id`, `icon`, `name`, `desc`, `fields` (поля формы) и `prompt(f)`, функцию, которая возвращает текст промпта. Инструмент сразу появится в AI-студии.
- **Новый AI-провайдер:** добавьте объект в `AI_PRESETS` в `lib/presets.js`.
- **Формулы:** все оценки собраны в `lib/scoring.js` с комментариями. Например, веса «спрос/конкуренция» задаются в `keywordScore`, а пункты чеклиста — в `videoSeo`.
- **Сломалась панель на YouTube:** вёрстка YouTube меняется, поэтому начните с селекторов в `content/*.js`. Если сломались данные без ключа — смотрите `lib/innertube.js`.
- Идеи с оценкой трудозатрат — в разделе «Что ещё можно добавить» в [COMPARISON.md](COMPARISON.md).
- Pull request лучше делать небольшим и по одной теме. Проверьте его в боковой панели, во вкладке и на youtube.com в светлой и тёмной теме.

## Честно об ограничениях

- Точных поисковых объёмов YouTube не публикует. «Спрос» — это индекс, рассчитанный по медиане просмотров топа выдачи и полноте автоподсказок, а не число поисков.
- Данные YouTube Studio (CTR, удержание, доход, время онлайна аудитории) через публичный API недоступны: для них нужны OAuth и YouTube Analytics API.
- VPH — это средний показатель за всё время жизни видео, а не за последний час. История подписчиков строится по замерам, которые делаются, когда вы открываете YouTube или TubeLens.
- Режим без ключа опирается на внутренний API сайта YouTube и может временно сломаться после изменений на стороне YouTube.
